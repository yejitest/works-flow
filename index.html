KEY FEATURES

Flow를 특별하게 만드는 것들

🔗

4-소스 교차 분석

단일 앱이 아닌 메일·메시지·캘린더·드라이브를 동시에 읽어 더 정확한 맥락 판단이 가능합니다.

🧠

다중 신호 조건 트리거

단일 이벤트에 반응하지 않습니다. 2개 이상의 소스에서 같은 맥락이 겹쳐야만 액션으로 판단합니다.

⚡

우선순위 자동 정렬

마감일, 참석자 수, 미응답 기간 등을 종합해 지금 당장 필요한 액션과 나중에 해도 되는 것을 구분합니다.

🌿

인라인 · 비침습적 제안

Push 알림이나 팝업 없이, 작업 흐름 안에서 자연스럽게 카드를 삽입합니다. 흐름을 끊지 않습니다.

🛡

본인에게만 보이는 분석

모든 분석 결과는 본인 화면에만 표시됩니다. 팀원이나 관리자는 제안 내용을 볼 수 없습니다.

🎛

완전한 수동 제어

무시, 거절, 끄기가 항상 가능합니다. Flow는 제안할 뿐 강제하지 않습니다. 선택은 항상 사용자에게 있습니다.

PRIVACY & TRUST

AI가 보는 것, 사용자가 결정합니다

Flow는 분석 결과를 절대 외부에 노출하지 않으며, 사용자가 언제든 기능을 끌 수 있습니다.

🔒

온디바이스 맥락 판단

메일·메시지 내용은 서버로 전송되지 않습니다. 신호 감지는 클라이언트 레벨에서 처리됩니다.

👁

분석 결과 = 나만 봄

Flow가 발견한 액션 카드는 본인 화면에만 나타납니다. 팀원, 관리자, 어드민 모두 볼 수 없습니다.

⚙️

언제든 끄기 가능

설정에서 Flow 기능 전체 또는 소스별로 ON/OFF를 조절할 수 있습니다. 기본값은 ON, 동의 없이 활성화되지 않습니다.
